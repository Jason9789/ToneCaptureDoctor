# ToneCaptureDoctor repository rules

- Before coding, read `README.md`, `AI_HARNESS.md`, and the relevant `PLAN.md` phase.
- Work on one issue and one phase at a time.
- Run the required tests and report `PASS`, `FAIL`, or `BLOCKED` with the environment.
- Do not add audio upload, secrets, unsafe amplifier routing, or unapproved dependencies.
- Keep `harness/state.json` aligned with Git evidence; do not mark a Gate complete without explicit human confirmation.
- Use `harness/prompts/review-task.md` for read-only independent review when a review subagent is assigned.
