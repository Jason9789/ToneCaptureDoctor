# Security / 보안

## English

Please do not disclose vulnerabilities in public issues when they include secrets, private recordings, or exploitable details. Use [GitHub security reporting](https://github.com/Jason9789/ToneCaptureDoctor/security) if enabled. Otherwise open a minimal issue that contains only a safe summary and a way to contact the maintainer.

The MVP is local-first and should not send audio to a server. Reports involving unexpected network requests, unsafe amplifier routing instructions, data loss, or bypasses of archive validation are high priority.

## 한국어

secret, 개인 녹음, 악용 가능한 세부 정보가 포함된 취약점은 공개 issue에 올리지 마세요. 활성화되어 있다면 [GitHub 보안 신고](https://github.com/Jason9789/ToneCaptureDoctor)를 사용하세요. 그렇지 않으면 안전한 요약과 maintainer 연락 방법만 포함한 최소 issue를 열어 주세요.

MVP는 로컬 우선이며 오디오를 서버로 보내면 안 됩니다. 예상하지 못한 네트워크 요청, 위험한 앰프 라우팅 안내, 데이터 손실, archive 검증 우회는 높은 우선순위로 처리합니다.
