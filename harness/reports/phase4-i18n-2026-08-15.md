## 구현

- `apps/web/src/i18n.ts`: 영어/한국어 리소스, 브라우저 언어 fallback, localStorage 선택 저장
- `apps/web/src/App.tsx`: 언어 selector, 전체 현재 Signal Health UI 번역, 로컬 측정 지표 표시
- `packages/audio-core`: peak, RMS, crest factor, noise floor window, clipping candidate, Hann FFT, dominant frequency, 50/60Hz hum candidate
- `apps/web/src/audioAnalyzer.worklet.ts`: AudioWorklet 입력 프레임 수집과 요약 metric 전송
- `apps/web/src/audioAnalysis.ts`: 입력 stream과 AudioWorklet 연결, 무음 gain으로 speaker feedback 방지
- 합성 fixture 테스트: sine, hard clipping, hum, rolling noise floor, malformed input

분석 엔진은 `algorithmVersion`을 결과에 포함하며 raw audio를 React state·서버·파일에 저장하지
않는다. AudioWorklet을 지원하지 않는 브라우저에서도 입력 연결 상태는 유지하고 분석 불가 상태를
별도로 안내한다.
