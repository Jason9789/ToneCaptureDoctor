# P0-002 audio input permission and device selection — 2026-08-15

## 작업

- Phase: P0 / PLAN Phase 3
- Issue: P0-002 — 사용자의 클릭 후 오디오 권한을 요청하고 선택한 장치를 표시한다.
- 브랜치: `feat/p0-002-audio-input-status`
- 런타임: bundled Node.js `v24.19.0`, npm `11.12.1`
- 실제 오디오 사용: 없음
- 오디오 서버 업로드: 없음

사용자의 “다음 진행” 지시에 따라 P0-001의 사람 Gate 확인 전에도 P0-002 구현을 시작했다. Gate 완료나 main 병합으로 간주하지 않으며, 실제 장비 검증은 별도로 남겨 둔다.

## 구현 범위

- Start 버튼을 누른 뒤에만 `getUserMedia({ audio })`를 호출한다.
- 악기 입력용 `autoGainControl`, `echoCancellation`, `noiseSuppression`을 `false`로 요청하고 채널 수는 최대 2채널 정책을 경고로 검증한다.
- 권한 거부, 브라우저 보안/지원 문제, 입력 장치 사용 불가 상태를 구분해 안내한다.
- `enumerateDevices()` 결과로 입력 장치 선택 UI를 제공한다.
- `MediaStreamTrack.getSettings()`의 sample rate, channel 수, 실제 처리 설정을 표시한다.
- Start/Stop, 장치 변경, track 종료, devicechange를 처리한다.
- 진행 중 요청이 unmount 또는 Stop 이후 완료되면 늦게 열린 stream을 즉시 정리한다.
- 오디오는 브라우저 세션 밖으로 전송하거나 저장하지 않는다.
- 안전한 instrument/Hi-Z 입력 안내와 speaker output 직접 연결 금지 문구를 유지한다.
